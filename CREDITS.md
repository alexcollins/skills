# Credits

Several skills here are rewrites of other people's work — condensed, merged and adjusted to fit
this set. The ideas that make them good are theirs; the mistakes in the rewrite are mine. Each
skill names what it was adapted from in its `metadata.adapted-from`.

|---|---|
| grill | [mattpocock/skills](https://github.com/mattpocock/skills) — grilling, grill-me, grill-with-docs, domain-modeling |
| spec | mattpocock/skills — to-spec, to-tickets |
| build | mattpocock/skills — implement, implement-spec, tdd, pr |
| diff-review | mattpocock/skills — code-review |
| debug | mattpocock/skills — diagnosing-bugs |
| architecture | mattpocock/skills — codebase-design, improve-codebase-architecture |
| prototype | mattpocock/skills — prototype |
| research | mattpocock/skills — research |

| polish | [jakubkrehel/skills](https://github.com/jakubkrehel/skills) — better-ui; [emilkowalski/skills](https://github.com/emilkowalski/skills) — emil-design-eng |
